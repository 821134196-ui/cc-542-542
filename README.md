# 影城放映机灯泡寿命与换灯管理

按影厅记录放映机型号、灯泡序列号、累计点亮小时与厂家更换阈值；排片后判断灯泡能否覆盖整场；
换灯按固定五步执行并留存试映记录；异常与延误均有处置，超阈值设备须放映主管批准，
最终放行由主管（非换灯人）会签。

## 启动（一条本地命令）

```bash
python3 run.py            # 重置并写入临界寿命样例，然后启动界面
python3 run.py --keep     # 保留已有数据启动
python3 run.py --port 9000
```

打开 http://127.0.0.1:8000 。仅依赖 Python 3.11 标准库，无需安装任何第三方包。

样例数据包含：

| 影厅 | 情形 |
|---|---|
| 1号厅 | 临界寿命（剩约 21h，更换前亮度偏低）；另有一场 5h 连映演示“无法覆盖整场” |
| 2号厅 | 已超厂家阈值，待放映主管批准临时使用 |
| 3号厅 | 正常 |
| 4号厅 | 异常熄灯，未开场次已自动转延误（开维修单修复后恢复） |
| 5号厅 | 临界但下一场短片可覆盖 |
| 备件 | `SP-WRONG-01` 为型号不符样例，开单时会被拒绝并登记事故 |

## 交付页面

- **影厅概览** `/`：影厅列表并列“下一场开始时间”与“剩余寿命”，给出覆盖判断
- **设备台账** `/ledger`：放映机型号、灯泡序列号/型号、累计小时、阈值
- **场次影响** `/shows`：寿命预测、可覆盖/不可覆盖、延误登记
- **换灯工单** `/tickets`：固定编号步骤、试映前后亮度成对展示与照片
- **异常处置** `/incidents`：六类事故的登记与处置结果
- **放行审批** `/approvals`：超阈值临时使用审批；最终放行在工单详情页会签

## 固定换灯步骤（不得跳步）

1. **断电** — 关闭电源并挂牌上锁
2. **冷却** — 等待灯泡冷却
3. **安装** — 拆下旧灯、装入型号匹配的新灯并重置计时器
4. **对焦** — 调整光路焦点
5. **试映** — 试映并比对更换前/后亮度（不足则不得通过、不得放行）

## 业务规则

- **时长累计**：放映机读数由模拟适配器返回，按场次同步，点亮小时只增不减；
  读数异常回退判为计时器重置失败并登记事故。
- **维修互斥**：同一放映机同一时间只允许一张占用中的工单（数据库锁 + 并发校验）；
  仅占用人可操作；完工或中途取消后释放窗口。
- **备件匹配**：备件型号必须等于放映机要求型号，不符即拒绝并登记“备件型号不符”。
- **拆下不复用**：旧灯泡序列号一旦标记 `removed`，永远不能重新登记为在用。
- **重置失败**：步骤 3 若放映机返回重置失败，旧灯泡保持在用、备件不出库，可重试或取消。
- **亮度不足**：试映后亮度低于放映机要求值时步骤保持未完成，记录前后成对数据与照片，
  调试后可重试。
- **超阈值审批**：超阈值设备默认不可覆盖场次，仅放映主管可批准 24 小时临时使用。
- **放行权限**：换灯人不能签署最终放行；最终放行须由非换灯人的放映主管签署，
  且工单必须完工、存在亮度合格的试映记录。
- **异常熄灯 / 延误**：熄灯登记事故并将未开场次自动转延误；修复完工后事故自动闭环。

## 存储与界面

- 设备/工单/审批等状态：SQLite（`data/cinema.db`，WAL 模式）
- 亮度照片：本地 PNG（标准库按流明生成，`data/photos/`）
- 放映机读数：模拟适配器 `cinema_lamp/sim.py`（状态持久化于 `data/adapter_state.json`）
- 界面：影院黑底、白字、金色状态标记

## 测试

```bash
python3 -m unittest discover -s tests -v
```

覆盖：时长累计、维修互斥（含 8 线程并发只允许一张工单）、备件匹配、放行权限，
以及拆下灯泡复用、超阈值审批、亮度不足、重置失败、中途取消、熄灯与延误，共 25 例。

## 目录

```
cinema_lamp/
  config.py    固定步骤编号、事故类型、阈值常量
  db.py        SQLite schema 与连接
  sim.py       模拟放映机适配器（读数/熄灯/重置失败钩子）
  photos.py    亮度照片 PNG 生成
  service.py   全部业务规则
  seed.py      临界寿命样例数据
  web.py       本地 Web 界面
run.py         一条命令启动
tests/         unittest 测试
```
